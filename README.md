# Elchin CO LTD – Field Sales App

Helps sales reps plan and run outlet visits and capture orders on the spot, so the warehouse gets accurate orders immediately.

## Who it's for
- **Field sales rep (Marek)**
- **Warehouse / order processor (Anna)**

## Features done
- mob app first page
- planning visit
- setting date and time for visit
